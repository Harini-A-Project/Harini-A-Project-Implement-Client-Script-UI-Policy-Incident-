# Harini-A-Project-Implement-Client-Script-UI-Policy-Incident-


## 📌 Project Overview

This project focuses on customizing the **ServiceNow Incident** table using **UI Policies, UI Policy Actions, and Client Scripts**.

The project was developed and tested using a **ServiceNow Personal Developer Instance (PDI)**.

## 🎯 Objectives

- Customize the Incident form.
- Implement UI Policies and UI Policy Actions.
- Implement Client Scripts for dynamic behavior and validation.
- Improve Incident data accuracy and user experience.

## 🛠️ Technologies Used

- ServiceNow
- Incident Management
- UI Policies
- UI Policy Actions
- Client Scripts
