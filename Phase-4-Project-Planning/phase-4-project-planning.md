# Phase 4 – Project Planning

## Project Title
Implement Client Script & UI Policy (Incident)

## 1. Project Objective

The objective is to configure the Incident form in ServiceNow using UI Policies and Client Scripts to provide dynamic field behavior and validation.

## 2. Project Implementation Plan

The project will be completed through the following milestones:

### Milestone 1 – Create UI Policy on Incident
- Create a UI Policy on the Incident table.
- Configure the required conditions.
- Name the UI Policy "High Impact Control".

### Milestone 2 – Create UI Policy Action – Urgency
- Create a UI Policy Action.
- Select the Urgency field.
- Configure the field as mandatory when the UI Policy conditions are satisfied.

### Milestone 3 – Create onChange Client Script
- Create an onChange Client Script.
- Configure the required field and script logic.
- Test the dynamic behavior when the field value changes.

### Milestone 4 – Create onSubmit Client Script
- Create an onSubmit Client Script.
- Add validation before the Incident form is submitted.
- Test the validation.

### Milestone 5 – Create onCellEdit Client Script
- Create an onCellEdit Client Script.
- Configure the required behavior for list editing.
- Test the functionality.

### Milestone 6 – Testing the Configuration
- Test the UI Policy.
- Test the UI Policy Action.
- Test all Client Scripts.
- Verify that the Incident form behaves as expected.
